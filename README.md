## 二、擋在中間的那一層

### 鏈路長甚麼樣

OpenAI 自己不收加密貨幣。ChatGPT Plus、Pro、API 的每一筆扣款，走的都是 Stripe。

Stripe 收到的是一串卡號和一組上下文資訊，它要在幾十毫秒裏同時看很多項，判斷這筆授權放不放：卡號前幾位對應的發卡機構和發卡國、你的 IP 所在地、你填的帳單地址國家、卡是不是預付卡、能不能走 3DS 驗證。

這些項裏有一項是**硬性的**，其餘是加權的。硬性的那一項就是**發卡地**。

### 發卡地為甚麼是硬性的

對某些發卡地，Stripe 這一層有區域性規則，整類不放行。OpenAI 自己的幫助文檔也寫了這個意思——付款人和發卡機構都需要位於受支援的地區，任一方不在，付款就可能被拒。

多家第三方排查指南的結論是一致的：香港發卡的卡在 OpenAI 這條鏈路上屬於處理器層面的攔截，不是銀行層面的。落到你這邊看到的現象就是：卡好好的，錢也夠，但訂閱頁面就是過不去。

這一層和你的操作完全無關：

| 你試過的 | 有沒有用 |
|---|---|
| 多充錢 | 沒用，不是餘額問題 |
| 換卡組織 | 沒用，不是屏蔽維度 |
| 換 IP、換裝置、換瀏覽器 | 沒用，發卡地改不了 |
| 掛代理到美國 | 沒用，反而可能更糟（下面會講） |
| 找免實名的卡 | 和這個無關 |

因為它根本不是在判斷「這個人可不可信」或者「這筆錢夠不夠」，而是在判斷「這串卡號是從哪兒來的」。一張卡的發卡地是寫死在卡號裏的，你改不了。

所以這個問題的正確問法不是「我該怎麼繞過去」，而是——**換一張發卡地能通過的卡**。
關於哪些發卡地會被攔、為甚麼會被攔，MothCard 官網有一篇更完整的拆解：[為甚麼你的虛擬卡在 AI 訂閱上會被拒](https://www.mothcard.io/zh-HK/blog/why-virtual-cards-get-declined-on-ai-subscriptions/)。

### 另外那些加權項，也會咬你

發卡地是門檻，過了門檻之後，其餘幾項會決定成功率：

- **IP 和帳單地址國家不一致**，是最常見的加權扣分項。拿一張某國發的卡配一個完全無關的 IP，風控會當作異常
- **帳單地址格式不對**，帳單地址與發卡地不一致，會引起報錯
- **3DS 走不通**，驗證該彈沒彈、或者彈了沒完成，授權就掛在那裏

## 三、這些流傳很廣的說法，是怎麼來的

**「要用免實名的卡。」**

免實名的卡通常來自那些不做 KYC 的小平台，而這類平台為了能讓用戶真的刷出去，往往會去找非主流地區的發卡渠道。所以有人用免實名的卡付成功了，真正起作用的是那張卡的發卡地，不是「免實名」這個屬性。

反過來，免實名的卡裏也有大量付不了 ChatGPT 的，因為它恰好是被屏蔽的發卡地。

**「要高權重卡段。」**

「卡段權重」這個詞，它想描述的現象是真的——同樣是虛擬卡，有些就是比別的好用。

用「權重」這個詞去描述它，問題在於它暗示這是個能花錢買到的等級，於是人們去找「更高權重」的卡，而不是去看發卡地和卡性質。方向一開始就偏了。

**「要換成 Visa」（或者反過來）。**

這條通常來自一次具體的成功經歷：某人換了張卡成功了，而那張卡剛好是另一個卡組織的。

但那張卡同時也換了發卡地。變量沒分離開，於是歸因給了卡面上最顯眼的那個 logo。

**「掛美國 IP 就能過。」**

這條不只是沒用，有時候是反作用。

風控會比對你的 IP 和帳單地址國家。如果你用一張某國發的卡，卻從一個美國節點提交，這個組合本身就是異常信號。免費或共享的 VPN 節點風險評分普遍偏高，被整段標記的情況也有。

正確的做法恰恰相反：**讓 IP 和帳單地址對上**，而不是刻意偽裝成另一個國家。

過去兩年裏，野卡、Dupay、bingo card、fomecard 接連停止服務。劇本幾乎一模一樣：先是提現變慢，然後客服不回，然後官網打不開，最後電報群禁言。留在卡裏和帳戶裏的餘額，大多沒拿回來。

這導致現在選卡，第一個問題不再是「費率多少」，而是「這家會不會也跑」。

MothCard 和那批平台有兩處結構性的不同：

**第一，需要 KYC。**

停服的那批普遍主打免實名。這兩件事是有關聯的——不做 KYC 通常意味着沒有合規框架，也就沒有一個可追責的主體。出事的時候你找不到人。

免實名讓開卡變快，讓受限地區也能用卡，這很好。

但 MothCard 也很快——最快 1 分鐘，你就能拿到卡，且大部分卡都允許受限地區申請。

這是比費率更值得看的一項。

如果一個平台只有一條發卡通路，那條通路出問題就是平台全停跑路——用戶自己在社區裏總結過這句話，「所有虛擬卡都逃不過上游影響」。

這個判斷對單通路平台是成立的，而 MothCard 是多通路平台，比單通路更有保障。

## 六、從註冊到付款，一步一步來

以 Glow 為例。整個流程大概十分鐘。

### 第 1 步 · 註冊

點擊邀請連結，用電郵註冊，下載 MothCard App。

### 第 2 步 · 完成 KYC

提交基礎身份資料，最快 1 分鐘過。

**一個常見的被拒原因：姓名和證件不一致。** 別把名字「整理」成更順眼的拼法，別調整姓和名的順序，別省略中間名。照着證件上印的逐字填。這是各類卡平台 KYC 被退回最高頻的原因，和平台本身沒關係。

別擔心，你屬於任何地區，都可以進行 KYC。

### 第 3 步 · 申請 Glow

在卡列表裏選 Glow，開卡費 $10，預存 $10。

註冊後你的帳戶裏會有一張 **$5 開卡抵扣券**，30 天有效。用上之後開卡實付 $5。

**這一步要有點耐心**：Glow 是審批開卡，不是提交就出卡。等審核結果出來再操作，中間不要反覆提交申請。

### 第 4 步 · 充 USDT 進錢包

App 內錢包支援 USDT 三條鏈：

| 鏈 | 說明 |
|---|---|
| **TRC20** | gas 最低，日常就用這條 |
| **Polygon** | 費用也低，適合資產本來在 Polygon 上 |
| **ERC20** | 以太坊主網 gas 偏高，小額充值不太划算 |

### 第 5 步 · 從錢包劃轉到卡

這一步最容易被跳過，也是最常見的「為甚麼刷不了」。

MothCard 是錢包和卡兩層：鏈上轉進來的錢先落在**錢包**裏，這時候卡裏的餘額還是零。要消費，得再做一次**劃轉**，把錢從錢包移到具體某張卡上。

這個設計的好處是你不用一次性把錢都押進卡裏，想花多少劃多少，剩下的留在錢包。

### 第 6 步 · 在 OpenAI 綁卡

這是最後一步，也是最容易在這兒摔的一步。按順序做，不要跳。

**付款前先做三件事：**

**① 檢查 VPN 和代理。**

風控會比對你的 IP 和帳單地址國家，Glow 是新加坡發卡，你如果從一個美國節點提交，這個組合本身就是異常信號。

**② 帳單地址填新加坡。**

Glow 是新加坡發卡，帳單地址要和發卡地對上。
隨便填一個其他國家的地址，大概率會充值失敗。

**③ 確認卡裏餘額夠。**

訂閱扣款是**含稅**的，實際扣款會比標價高一點。

**然後開始綁卡：**

1. 登入 ChatGPT，進升級頁面
2. 填卡號、有效期、CVV
3. 帳單地址按發卡地填
4. 提交
5. 如果彈出 3DS 驗證，看 MothCard App 的推送通知，按提示完成。

**如果被拒了，最重要的一條：不要連續重試。**

每次失敗都可能被記成一次可疑交易，連續失敗會觸發臨時鎖定，把問題變複雜。

**還有一條備用路徑**：網頁端反覆不行的話，可以試試把卡加進手機錢包，然後從 ChatGPT 的行動 App 裏訂閱。這條路由走的是 Apple 或 Google 的扣款體系，和網頁端直接提交卡號不是同一條鏈路。

### 第 7 步 · 管好續訂

這一步沒人提，但它決定你三十天後會不會突然掉回免費版。

ChatGPT Plus 每 30 天自動扣一次。如果扣款那天卡裏餘額不夠，續訂失敗，OpenAI 會在接下來幾天重試一兩次，一直失敗就會把帳號降回 Free。

對話歷史不會丟，但 Plus 的功能沒了。

兩個辦法，選一個：

- 卡裏常備 $25～$30，別讓餘額見底
- 在日曆上設一個每月提醒，比扣款日提前三天去充

補充一句：**訂閱不用了記得解綁。** 授權一旦發生就會產生費用，這件事在凍結卡之後依然成立。
